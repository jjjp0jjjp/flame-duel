# 烈焰對決 Flame Duel

瀏覽器格鬥遊戲，單一 HTML 檔，不需安裝。支援本機雙人、對電腦，以及線上對戰（rollback 網路同步）。

線上版：https://flame-duel-fighter.pages.dev

## 角色

| 角色 | 定位 | 特色 |
|---|---|---|
| 烈 | 迅捷・波動彈 | 火球、無敵升龍、踵落（中段） |
| 鋼 | 剛猛・衝擊拳 | 重攻擊霸體、鐵山靠、錘擊（中段霸體） |
| 影 | 疾風・二段跳 | 瞬移、手裏劍、背刺（打到身後）、二段跳 |
| 雷 | 遠攻・天雷 | 雷球、定點落雷、三段電掌、集氣快 |
| 岩 | 投技・岩石 | 指令投、反擊架勢、山崩（霸體）、難擊退 |
| 霜 | 冰結・遠攻 | 冰錐、冰牆（擋飛行道具）、穿透四次的絕對零度、寒流（拉近） |
| 嵐 | 疾風・連腳 | 多段踢技、吸風（拉近）、空中旋風、無敵五段的天嵐旋 |
| 月 | 長棍・間合 | 遠距普通技、撐竿飛擊、掃棍（下段）、劈棍（中段） |
| 拳 | 拳擊・連打 | 五段連打、霸體直拳、燃魂強化（傷害 +25%）、八段超必殺 |
| 蠍 | 鎖鏈・毒 | 鎖鏈拉近、毒雷陷阱、中毒（持續扣血、不會致死）、指令投 |
| 蝶 | 舞扇・迴旋 | 會飛回來的迴旋扇、無敵後跳、空中滯空攻擊、空中更靈活 |
| 機 | 機甲・砲擊 | 火箭拳、往前排開的飛彈雨、全畫面光束、飛行道具傷害減半 |
| 刃 | 居合・一閃 | 居合斬穿到對手背後、破甲斬（被擋也會破防）、飛燕斬、武士刀 |
| 巫 | 咒術・吸魂 | 追蹤魂球、詛咒陣（對手傷害 -25%）、命中吸血 |
| 獸 | 狂暴・撲擊 | 飛撲指令投、四段撕咬、咆哮吸走 30 氣、低體力時傷害 +30% |
| 羽 | 弓術・遠射 | 極快的速射（中箭會緩速）、拋射、後躍射、五發箭雨 |


每位角色的**基本技**（輕拳、重拳、輕腳、重腳、空中輕拳、空中腳）都有專屬動作、數值與特殊效果，例如烈的迴旋炎腳燃燒並擊倒、鋼的鋼錘是從上往下劈的中段、影的迴影踢會穿到對手身後、雷的電擊掌命中停頓更久、嵐的風拳把人吸近、刃的斬擊被擋也會削血、蝶的雙扇吸走對手的氣；動作定義在 `src/js/16b-anim.js`，招式資料在 `src/js/12b-basics.js`。掃堂腿與投技是共通系統。

每位角色另有一種**流派**（例如烈「烈拳」、鋼「鐵壁」、月「迅棍」、蠍「劇毒」），選角時切換，會改動部分招式與能力；用 `ROWSTY=1 node tools/balance.cjs` 可比較流派相對標準的強弱（目前約 45%～54%）。
每個角色的 11 個指令技（→+輕拳、→+重拳、→+輕腳、→+重腳、←+輕拳、←+重拳、←+重腳、↓+輕拳、↓+重拳、↓+輕腳、空中重拳）都是專屬的，另外還有 6 個必殺技（第六個是 ↓+投技，耗 50 氣），名稱與特性見遊戲內說明的「角色」分頁或暫停畫面。中段（含所有跳躍攻擊）要站著擋、下段要蹲著擋，擋錯會被打中；中段招式起手時頭上會閃黃色 ▼，下段在腳邊閃藍色 ▲。

同角色對戰時 P2 會自動換第二套配色。主選單可用滑鼠或方向鍵選角（先選 P1，自動切到 P2），也有隨機選角、難度與場景縮圖。

## 遊戲模式

- **單人 vs 電腦**：三種難度，加上四種電腦性格（猛攻、防守反擊、遠攻、投技；預設依角色，也可指定或隨機）。普通以上的電腦會拆投、確反揮空、對空、精準招架、在對手防禦耐久快空時連續施壓，困難還會用迅移取消延長連段或保命；開了場景機關時會躲火山噴發；也會記住你的習慣（常跳、常投、常放飛行道具、常防禦）調整打法。
- **街機模式**：依序打倒其他 4 位角色（後兩場難度提高），最後挑戰體力 ×1.3 的強化版自己；輸了可以接關，通關紀錄依角色保存。每場開打前有雙方對話，通關後顯示該角色的結局。
- **雙人對戰**、**連線對戰**。
- **爬塔挑戰**：一路打電腦，每贏一層從 3 張強化卡選 1 張（可疊加），越高層越強、每 5 層精英層帶隨機規則；輸了結束，保存最高層數。強化效果會寫進重播。
- **每日挑戰**：用日期當種子，每天一題固定的對戰（角色、場景、突變規則、強化版對手），依剩餘體力與時間計分。
- **3 對 3 隊伍戰**：各選 3 位依序上場，一回合決勝，贏的保留體力並回復 20%。
- **生存模式**：無限連戰，每勝回復 25% 體力、每 3 勝難度提高，保存各角色最佳紀錄。
- **訓練模式**：判定框（F2）、招式幀數與命中／被防的優劣幀、木樁行為（站立／蹲防／隨機防禦／跳躍／防後反擊／重播錄製）、錄製木樁動作、每個角色 4 題連段挑戰。
- **新手教學**：9 步互動教學，從走路到超必殺。
- **畫質**：畫布依實際顯示大小與螢幕像素密度渲染（最高 2.5 倍，大螢幕可顯示到 1600px 寬）。設定裡可選自動／高／標準／省電；「高」另有地面倒影、場景光線、暗角與重擊閃光，「自動」在掉到約 50fps 以下時會自己降一級。這些都只影響繪圖，不影響判定與連線同步。
- 按鍵可在「設定」更改（P1、P2 各自），也可調主音量／音樂／音效與觸控按鈕大小；手機使用虛擬搖桿。

## 進階系統

- **精準招架**：攻擊快打到時按一下 →（朝對手），7 幀內被打到就不受傷並可反擊。
- **確反**：在對手收招時打中，傷害 +20%、硬直更長。
- **受身／強制倒地**：被打飛落地前按攻擊鍵翻滾起身；投技、掃堂腿、超必殺不能受身。落地按住 ↓ 可延後起身。
- **撞牆**：被打飛撞牆會反彈，可追擊。
- **爆氣**：被連段時按 投技＋必殺 震開對手，每回合一次。
- **防禦耐久**：一直防禦會減少，歸零破防。
- **迅移取消**：出招中同時按 輕拳＋重拳＋輕腳（50 氣）取消收招；命中時對手多硬直。
- **簡易操作**：設定裡 P1／P2 各自切換；命中後連按攻擊鍵自動接 輕→輕腳→重拳→必殺，傷害 ×0.85。
- **場景機關**（選單可開關）：夜城屋頂定時颳強風、黃昏港木箱牆可撞破、極光雪原地面濕滑、火山口定時噴發、竹林道場定時鐘響（雙方加氣）。
- **突變規則**（選單可複選或每場隨機）：低重力、狂熱、劇毒擂台、玻璃大砲、吸血擂台、持久戰、逆轉（落後方補強）、天氣多變（雨天、強風、濃霧輪流）。
- **成就**：15 個（例如十連擊、一命通關、全角色制霸），只存在本機、不影響對戰。
- **畫風**：設定裡可切換「街機」（粗墨線、硬邊陰影、斜切血條、底部分段超必殺槽、衝擊星芒、觀眾與視差背景、斜體回合字樣）或「經典」。

以上會影響模擬的設定（簡易操作、場景機關）都會寫進連線開局訊息與重播資料，雙方結果一致。

## 線上對戰怎麼運作

1. **房間代碼（配對）**：`/api/ws` 由 Cloudflare Durable Object（`rooms-worker`）負責，一間房只收房主＋一位對手，只轉送 WebRTC 的 offer/answer，連上後就關閉 WebSocket。
2. **P2P 對戰**：對戰資料走 WebRTC DataChannel（unordered、不重傳），玩家之間直連。
3. **TURN 中繼**：配對成功時才向 Cloudflare Realtime TURN 申請 2 小時的短期憑證；直連打不通時自動改走中繼。
4. **手動代碼備援**：直接開檔案（file://）或伺服器連不上時，改用手動複製代碼。
5. **不同步自動修復**：雙方每 30 幀互傳狀態雜湊；不一致時房客向房主要「輸入都已確認」那一幀的完整狀態，從那裡回滾重算。
6. **限流**：同一個 IP（IPv6 以 /64 計）10 分鐘內最多建立／加入 40 次房間，超過時遊戲會提示稍後再試（計數器是以 `gate:<ip>` 命名的 `Room` Durable Object，不需要新增綁定）。
7. **再戰換角**：結算畫面按 ←／→（手機點畫面左右兩側）挑下一場的角色，選擇會跟著再戰邀請送給對方。
8. **斷線重連**：用房間代碼配對的對戰中途斷線時，雙方會用同一個代碼自動重新握手（最多等 20 秒），接回後從各自保留的狀態繼續，沒送到的輸入自動補送。手動代碼配對不支援。
9. **觀戰**：房主建立房間前勾選「開放觀戰」，就能把代碼或觀戰連結（`#w=代碼`）給觀眾。觀戰者經伺服器和房主握手後，由房主直接傳送「雙方都已確認」那一幀的快照與之後的輸入，觀戰者用同一套模擬重算，畫面和雙方一致。開放觀戰時房主在對戰中會保留配對連線（用來接新觀眾、也擋掉新的對手），每間房最多 8 位觀眾。

## 重播

遊戲是確定性的，所以只要記錄每一步雙方的輸入就能完整重現。單人、雙人、連線對戰結束後按 R（或畫面下方按鈕）會把這場的輸入壓縮成 `#rp=` 連結，一般一場約 1～6 千字；最近一場也會存在瀏覽器，選單可直接「觀看上一場重播」。

## 開發

**改程式請改 `src/`，不要直接改 `index.html` 或 `claude-artifact/fighter_v2.html`**，改完執行：

```bash
npm install            # 只需要一次（裝 Playwright）
npm run build          # 產生兩個版本
npm test               # 檢查產生的檔案是否最新 + 遊戲本體測試
```

`tests/game.test.cjs` 會檢查：兩個版本都能載入並執行各模式、同樣輸入的結果完全一致（確定性）、從快照回滾重跑的結果一致（連線對戰靠這個）、每個角色的連段挑戰都打得出來、新手教學可以完成。
`tests/visual.test.cjs` 把固定場景（HUD、16 位角色、機關、訓練畫面）畫出來和基準比對，並檢查手機橫放／直放的版面；畫面是刻意改的時候用 `npm run test:visual:update` 更新基準。`tests/perf.test.cjs` 量最重場景（雙方超必殺＋火山＋觀眾）和一般場景的耗時倍數。建置時也會檢查有沒有重複的頂層名稱（所有程式共用同一個全域範圍，重名會悄悄蓋掉）。GitHub Actions（`.github/workflows/ci.yml`）每次 push 都會跑這些測試和連線測試。

### 平衡模擬

```bash
node tools/balance.cjs 60 2                    # 電腦對電腦，每組 60 場、困難難度，輸出勝率表
PATCH='CH[4].hp=112' node tools/balance.cjs 40 # 先套用試調的數值再模擬
PATCH='HZ=1;G.stage=3' node tools/balance.cjs 40 # 在火山口開機關模擬
node tools/frames.cjs                          # 每招的起手、傷害、命中／被防優劣幀，列出離群招式
node tools/frames.cjs 烈                        # 單一角色的完整幀數表
```

平衡模擬用無性格的中立打法（遊戲裡的電腦另有性格）。結果反映的是「這個 AI 用這個角色」的強弱，只適合抓出明顯失衡，不能取代真人試玩。目前 16 位角色（困難難度，每組 60 場；電腦會用招架、迅移取消、爆氣，也會躲火山）的平均勝率約 47%～53%。`tools/frames.cjs` 目前沒有需要處理的離群招式，4 項已知特色（影的輕攻擊、岩的霸體重拳、蠍的毒）列在工具裡的 `KNOWN`。

## 部署

```bash
# 1. 房間 Worker
cd rooms-worker
wrangler secret put TURN_KEY_ID      # Cloudflare Realtime TURN key id
wrangler secret put TURN_KEY_TOKEN   # 該 key 的 secret（只在建立時顯示一次）
wrangler deploy

# 2. Pages（專案需綁定 Durable Object：ROOMS → flame-duel-rooms 的 Room）
cd ..
node pages/build.mjs
wrangler pages deploy dist --project-name flame-duel-fighter
```

## 連線測試

## 注意

- 4 位數代碼可被猜中，但有依 IP 限流；猜中也只能闖進一場對戰，拿不到其他資料。
- TURN 憑證只在配對成功後發出、2 小時過期；若被濫用可在 Cloudflare 後台撤銷 TURN key。機密值只放在 Worker secrets，不要提交到這個 repo。
